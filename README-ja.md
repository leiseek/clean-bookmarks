# ブックマーククリーナー

Chrome と Microsoft Edge のリンク切れを確認し、HTML バックアップのダウンロード完了後に、選択・確認したブックマークを削除します。

[简体中文](README.md) · [English](README-en.md) · **日本語** · [한국어](README-ko.md) · [Français](README-fr.md) · [Español](README-es.md)

## インストール

[Edge Add-ons](https://microsoftedge.microsoft.com/addons/detail/bfplmmnmgnfelmjdabmgjpfafnocnhna) からインストールできます。ストア版とメインブランチは異なる場合があります。

ソースから使う場合は Chrome 102 以降、または同等の Manifest V3 API に対応する Edge を使用してください。リポジトリをダウンロードし、`chrome://extensions/` または `edge://extensions/` で開発者モードを有効にして、「パッケージ化されていない拡張機能を読み込む」から `manifest.json` のあるフォルダーを選択します。ビルドは不要です。

## 使い方と判定

1. 拡張機能アイコンからスキャンを開始します。ポップアップを閉じてもバックグラウンドで続行できます。
2. 結果を確認し、行をクリックして元のリンクを手動で確認します。
3. 削除候補を選択し、確認します。全ブックマークのバックアップ完了後に削除します。

| 状態 | 判定 | 削除対象 |
| --- | --- | --- |
| 有効 | HTTP(S) の 2xx | いいえ |
| 無効 | HTTP(S) の 404/410 | 選択・確認後のみ |
| 確認できません | 通信障害、タイムアウト、401/403、429、5xx など | いいえ |
| スキップ | `chrome:`、`edge:`、`file:`、`javascript:` など | いいえ |

ログイン、地域制限、一時的な障害などにより判定が変わる場合があります。旧バージョンの結果は再スキャンが必要です。中断されたスキャンは最初からやり直せます。

## バックアップと復元

バックアップはブラウザーで読み込める HTML 形式で、ブラウザーの**ダウンロード先フォルダー**に保存されます。ダウンロードが失敗・中断した場合は削除しません。結果ページからバックアップだけを作成することもできます。

復元にはブラウザーのブックマーク管理画面で HTML インポートを選択してください。既存データに追加されるため、重複が生じる場合があります。削除処理の一部でエラーが起きた場合、完了済みの削除は自動で戻りません。バックアップを確認してください。

## プライバシーと開発

テレメトリーや開発者のバックエンドはありません。結果と処理状態はブラウザー内に保存されます。スキャン時はブックマーク先へ直接通信し、ログイン Cookie は送信しません。バックアップや不具合報告には個人情報を含めないよう注意してください。

Node.js 22 以降で `npm test` と `npm run check` を実行できます。外部依存はありません。削除や復元の変更は専用ブラウザープロファイルで検証してください。[問題の報告](https://github.com/leiseek/clean-bookmarks/issues) と翻訳・コードの貢献を歓迎します。
