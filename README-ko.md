# 북마크 클리너

Chrome과 Microsoft Edge에서 깨진 링크를 확인하고, 전체 HTML 백업 다운로드가 완료된 후 사용자가 선택하고 확인한 북마크를 삭제합니다.

[简体中文](README.md) · [English](README-en.md) · [日本語](README-ja.md) · **한국어** · [Français](README-fr.md) · [Español](README-es.md)

## 설치

[Edge Add-ons](https://microsoftedge.microsoft.com/addons/detail/bfplmmnmgnfelmjdabmgjpfafnocnhna)에서 설치할 수 있습니다. 스토어 버전과 메인 브랜치의 내용은 다를 수 있습니다.

소스 설치에는 Chrome 102 이상 또는 해당 Manifest V3 API를 지원하는 최신 Edge가 필요합니다. 저장소를 다운로드하고 `chrome://extensions/` 또는 `edge://extensions/`에서 개발자 모드를 켠 뒤, 압축해제된 확장 로드로 `manifest.json`이 있는 폴더를 선택합니다. 빌드가 필요하지 않습니다.

## 사용 및 판정

1. 확장 아이콘에서 검사를 시작합니다. 팝업을 닫아도 백그라운드에서 계속 진행할 수 있습니다.
2. 폴더별 결과를 확인합니다. 북마크 행을 클릭하면 원래 링크를 열어 확인할 수 있습니다.
3. 무효 후보를 선택하고 정리를 확인합니다. 전체 북마크 백업이 완료된 후 선택 항목을 삭제합니다.

| 상태 | 규칙 | 정리 대상 |
| --- | --- | --- |
| 유효 | HTTP(S) 2xx | 아니요 |
| 무효 | HTTP(S) 404/410 | 선택 및 확인 후 |
| 확인 불가 | 네트워크 오류, 시간 초과, 401/403, 429, 5xx 등 | 아니요 |
| 건너뜀 | `chrome:`, `edge:`, `file:`, `javascript:` 등 | 아니요 |

로그인, 지역 제한, 일시적 장애로 결과가 달라질 수 있습니다. 삭제 전에 직접 확인해 주세요. 이전 버전의 결과는 다시 검사해야 합니다. 중단된 검사는 처음부터 다시 시작할 수 있습니다.

## 백업 및 복구

백업은 브라우저에서 가져올 수 있는 HTML 형식이며, 브라우저에 설정된 **다운로드 폴더**에 저장됩니다. 다운로드가 실패하거나 취소되면 삭제하지 않습니다. 결과 페이지에서 백업만 실행할 수도 있습니다.

복구하려면 브라우저 북마크 관리자에서 HTML 가져오기를 선택합니다. 기존 북마크에 추가되므로 중복이 생길 수 있습니다. 삭제 중 오류가 나면 일부만 완료될 수 있으며 자동으로 되돌리지 않습니다. 백업을 확인하고 다시 검사해 주세요.

## 개인정보 및 개발

원격 분석이나 개발자 백엔드는 없습니다. 결과와 작업 상태는 브라우저 내부에 저장됩니다. 검사 시 북마크 대상에 직접 요청하며 로그인 쿠키를 전송하지 않습니다. 백업을 안전하게 보관하고 오류 보고에서 개인 URL과 토큰을 제거해 주세요.

Node.js 22 이상에서 `npm test`와 `npm run check`를 실행할 수 있습니다. 외부 의존성은 없습니다. 삭제와 복구는 별도 브라우저 프로필에서 확인해 주세요. [오류 보고](https://github.com/leiseek/clean-bookmarks/issues), 번역 및 코드 기여를 환영합니다.
