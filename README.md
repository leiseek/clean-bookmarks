# 收藏夹清理 · Bookmark Cleaner

为 Chrome 和 Microsoft Edge 检查失效书签，在完整 HTML 备份下载完成后，清理你确认选中的链接。

## 功能

- 按文件夹展示书签，区分有效、失效、无法确认和跳过，显示 HTTP 状态或检测原因。
- 仅允许选择本次检测返回 HTTP 404/410 的 HTTP(S) 书签，清理前再次确认。
- 自动导出当前完整书签树；浏览器确认备份下载完成后才开始删除。
- 保留无法确认的链接、内部页面、本地文件、书签脚本等特殊协议书签。
- 关闭弹窗后继续在后台扫描；再次打开可查看进度，扫描中断后可重新开始。
- 随浏览器语言显示简体中文、英语、日语、韩语、法语或西班牙语。

## 安装

### Edge 商店

打开 [Edge 插件商店页面](https://microsoftedge.microsoft.com/addons/detail/bfplmmnmgnfelmjdabmgjpfafnocnhna)，按页面提示安装。商店发布版本可能与本仓库主分支不同。

### 从源码加载

需要 Chrome 102+，或支持相应 Manifest V3 API 的新版 Microsoft Edge。

1. 下载并解压本仓库，或运行：

   ```bash
   git clone https://github.com/leiseek/clean-bookmarks.git
   ```

2. 打开 `chrome://extensions/`；Edge 用户打开 `edge://extensions/`。
3. 开启「开发者模式」，选择「加载已解压的扩展程序」。
4. 选择包含 `manifest.json` 的 `clean-bookmarks` 文件夹。

扩展可以直接运行，无需构建。更新源码后，在扩展管理页面点击重新加载，并重新打开弹窗或结果页。

## 使用

1. 点击工具栏中的扩展图标，再点击「扫描收藏夹」。可关闭弹窗，稍后重新打开查看进度。
2. 扫描完成后，打开「查看扫描结果」，按文件夹检查检测状态；点击书签行可打开原链接核实。
3. 手动勾选失效候选，或点击「全选失效链接」。从弹窗的「清理失效链接」进入时，会预选已确认的失效候选。
4. 点击清理并确认。扩展会先备份**当前全部书签**，等待下载完成，再删除所选书签。

结果页也提供「备份当前收藏夹」，可独立导出完整备份。

## 检测规则与边界

| 状态 | 判断规则 | 可清理 |
| --- | --- | --- |
| 有效 | HTTP(S) 请求返回 2xx | 否 |
| 失效 | HTTP(S) 请求返回 404 或 410 | 经用户选择和确认后 |
| 无法确认 | 网络错误、超时、401/403、429、5xx、其他异常响应或无法读取状态 | 否 |
| 跳过 | `chrome:`、`edge:`、`file:`、`javascript:`、`mailto:` 等非 HTTP(S) 协议 | 否 |

请求先使用 `HEAD`；服务器返回 405/501 时改用 `GET`，收到响应头后停止读取正文。每次请求最多等待 10 秒，逐个检测，书签之间间隔约 300 毫秒。

检测结果反映扫描时的网络响应。登录状态、地区限制、反爬策略和临时故障都可能影响判断；返回 200 的错误页面也可能被当作有效页面。删除前请打开候选链接核实。旧版扫描结果会标为无法确认，重新扫描后才能清理。

## 备份与恢复

- 备份采用浏览器可导入的 Netscape Bookmark HTML 格式，保留文件夹层级、书签标题和 URL。
- 文件保存到**浏览器设置的下载目录**，可在下载列表中查找；扩展不会指定保存到桌面。
- 文件名类似 `bookmarks_backup_2026-10-29T12-34-56-789Z.html`，使用 UTC 时间，并避免覆盖同名文件。
- 下载失败、中断或备份文件不可用时，清理停止。下载期间书签 URL 被修改时，也会停止清理。

恢复时，打开 Chrome 或 Edge 的书签管理器，找到「导入书签」功能，选择备份 HTML 文件。导入通常会追加到现有书签，可能产生重复条目。

删除过程无法保证整批回滚。如果个别书签在删除期间被修改或拒绝删除，操作可能部分完成；请根据提示检查备份并重新扫描。后台重启后不会重复执行已中断的删除任务。

## 隐私与权限

扩展没有账户系统、遥测或开发者后端。书签扫描结果和任务状态保存在当前浏览器的扩展本地存储中。扫描会直接访问书签指向的网站，包括内网站点；目标网站及网络服务仍能看到这些请求。请求设置为不携带浏览器登录 Cookie，因此需要登录的页面可能无法确认。

| 权限 | 用途 |
| --- | --- |
| `bookmarks` | 读取书签树，删除用户确认的失效书签 |
| `storage` | 保存扫描结果、进度和待完成的备份任务 |
| `downloads` | 导出 HTML 备份并确认下载状态 |
| `http://*/*`、`https://*/*` | 在扩展后台检测不同网站的链接 |

备份文件包含完整书签信息，请妥善保存。报告问题时，请隐去私有网址、访问令牌和个人信息。

## 常见问题

**关闭弹窗会停止扫描吗？**

关闭弹窗后扫描可继续。浏览器退出、扩展重载或后台异常终止可能中断扫描；再次打开会提示重新扫描，从头开始。

**为什么打不开的链接没有进入清理列表？**

只有返回 404/410 的 HTTP(S) 链接可以清理。网络连接失败或网站拒绝访问时，扩展保留链接，供你手动检查或稍后重试。

**备份迟迟没有完成怎么办？**

在浏览器下载列表中检查是否被暂停、取消或等待确认。清理会等待备份完成；取消或失败后不会删除书签。

## 开发与测试

扩展使用原生 JavaScript、HTML 和 Chrome Extensions API，没有运行时第三方依赖。测试需要 Node.js 22+，可以直接运行：

```bash
npm test
npm run check
```

测试使用 Node.js 内置测试工具、本地 HTTP 服务及模拟 Chrome API，覆盖检测分类、超时取消、备份完成与失败、后台重启、特殊字符导出和页面状态。语法检查及模拟测试不能替代真实浏览器验证。

```text
background.js       扫描、状态恢复、HTML 导出及备份后清理
popup.html / .js    工具栏弹窗、扫描进度与操作入口
results.html / .js  按文件夹展示结果、选择与确认清理
_locales/           六种语言的界面文案
icons/              扩展图标
tests/              无外部依赖的回归测试
manifest.json       扩展配置与权限
```

提交涉及书签删除的改动前，请在独立测试浏览器配置中验证：加载扩展、扫描、关闭并重开弹窗、取消备份、完成清理，以及将生成的 HTML 重新导入。使用临时书签验证恢复结果。
